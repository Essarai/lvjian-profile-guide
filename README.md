# 律见 · 律师定位填写向导

渐进式填写网页：五个核心主题、可编辑定位草稿、按主题补充资料、浏览器自动保存和 JSON 导出。

点击右上角“体验填写示例”，查看虚构律师林知远的资料。人物、经历、案例、收费和经营数据全部为虚构演示，不是法律建议、真实业绩或市场验证结果。示例独立保存，不覆盖个人填写；退出示例返回个人资料。

示例统计口径：2026年10月，全渠道咨询30人，其中业务匹配18人；付费10人，每人1单（咨询8单、案件2单）。自媒体有效咨询12人，其中匹配5人、付费3单（咨询2单、案件1单）。目标为未来改善匹配度，不是已实现结果。

## 本地运行

无需安装依赖，在项目目录运行 `python3 -m http.server 4317 --directory dist`，打开 http://localhost:4317 。也可直接打开 dist/index.html。

## 数据与功能边界

用户资料仅保存在浏览器 localStorage，没有后台收集或跨设备同步。草稿由模板整理，未接入大模型。补充资料不会自动改写已确认的草稿。示例与个人填写使用不同存储键；刷新默认返回个人填写。导出示例时附带 example 标记。

静态文件位于 dist/。公开体验站：https://lvjian-profile-guide-essarai.essaraic.chatgpt.site/
